# Anti-slop audit: OmniProxy operator console

Date: 2026-10-26
Scope: `/pengatur` (8 pages, 2 themes, 1440 / 390)
Method: Playwright + Chromium, live console on `:3151`, computed styles and WCAG contrast math. No test files added.
Design read: monochrome operator console, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

Verdict: **FAIL** on Hard Gate. Six findings block delivery, all in CSS/layout, none require a redesign.

---

## HIGH: Hard Gate

### H1. Stats and Logs are unusable on a phone (R-03)

`src/ui.ts:466` raises the table grid to a 720px floor:

```css
.grid-2:has(.table) { grid-template-columns: repeat(auto-fit, minmax(720px, 1fr)); }
```

The mobile override at `src/ui.ts:2053` sets `.grid-2` back to one column, but `.grid-2:has(.table)` is more specific (0,2,0 vs 0,1,0), so the 720px floor survives at 390px.

Measured at a 390px device, touch emulation on:

| Page | layout viewport | grid columns |
|---|---|---|
| `/pengatur/stats` | **1238px** | `720px` |
| `/pengatur/logs` | **736px** | `720px` |

Chrome shrink-to-fits the whole page, so 14px copy renders at roughly 4.4px and every breakdown table is cut at the right edge. Screenshot: `/tmp/shots/m-stats.png`.

A second source kept Stats wide after the grid was fixed: the screen-reader heatmap table carried `.sr-only` directly on the `<table>`. A table treats `width: 1px` as a suggestion and grew to 1206px, outside the clip. It is now wrapped in `<div class="sr-only">`.

Fix: re-assert the fold with equal specificity inside the 720px block:

```css
@media screen and (max-width: 720px) {
  .grid-2:has(.table) { grid-template-columns: minmax(0, 1fr); }
}
```

### H2. Providers table is clipped on desktop, and its header never folds (R-03, C-2)

`src/ui.ts:917-925` sums to more than the canvas:

```
250 + 38% + 360 + 96 + 96 + 112 + 1%  ->  1282px table in a 1150px wrapper at 1440px
```

The rightmost column is the action column. At 1440 the `Edit` and `Disable` buttons are cut mid-word ("Dis"). Screenshot: `/tmp/shots/slop-light-providers.png`. The action cell is only reachable by horizontal scroll, which is the one thing a registry row must never require.

Second defect in the same table: `providers-ui.ts:259-264` appends the header `<tr>` straight to `<table>`, never inside `<thead>`. The mobile fold hides `.table thead`, so nothing is hidden: a desktop-shaped 7-column header strip stays above the folded rows (`/tmp/shots/m-providers.png`).

Fix:
- wrap the header in `<thead>` in `tableHead()` / `drawTable()`;
- drop the fixed `38%` / `360px` widths, let the URL column truncate (`.providers-table td:nth-child(2) { max-width: 240px; overflow: hidden; text-overflow: ellipsis; }`) and let the table size to its wrapper.

### H3. Muted text fails WCAG AA in dark mode, and on grey rows in light (R-25)

`--text-3: #737373` is the colour of every table header, KPI label, meta line and page eyebrow.

| Pair | Ratio | Need |
|---|---|---|
| `#737373` on `#111111` (dark surface) | **3.98** | 4.5 |
| `#737373` on `#000000` (dark canvas) | **4.43** | 4.5 |
| `#737373` on `#f5f5f5` (light row hover, `ui.ts:852`) | **4.35** | 4.5 |

Confirmed live: `palette-kbd`, `fig-label`, `split-head`, table `th`, `.meta` all report 3.98 in dark.

Fix: light `--text-3: #6b6b6b` (4.89 on `#f5f5f5`), dark `--text-3: #8a8a8a` (5.47 on `#111111`, 6.09 on black). Tokens only, no markup change.

### H4. Gemini provider tag fails AA in light (R-25)

`--prov-gemini: #0070f3` on its own wash (`#ebf4fe`) is **4.08:1** at 11px. Every other provider hue passes. Confirmed live on Overview, Keys, Providers, Models, Stats.

Fix: light `--prov-gemini: #0057c2` (6.0:1 on the wash). Dark `#3291ff` already passes at 5.96.

### H5. Touch targets are 40px, not 44 (R-03)

`src/ui.ts:1867` sets `--tap-sm: 40px` under `pointer: coarse`. Every `.btn-sm`, table link and segmented control inherits it. Measured on a 390px touch device: `Ctrl K` 90x40, `Refresh` 89x40, `Add provider` 122x40, `Edit` 42x40, keys links 39x40.

Fix: `--tap-sm: 44px` in the coarse-pointer block (and the `.check` / table-control rules that already reference the token follow automatically).

### H6. Em dash in user-facing copy (R-02)

Two strings, both rendered:

- `src/audit-ui.ts:148` — `"capped at " + limit + " — more may exist"`
- `src/app.ts:631` — `professional (${category}) — paid plan required`

Fix: comma or colon. `"capped at N, more may exist"`, `"professional (X), paid plan required"`.

## MEDIUM: Purpose-Gate

### M1. No design direction document (R-37)

The direction exists, but only as a comment at `src/ui.ts:1-18` ("Vercel style"). A future contributor cannot tell which parts are system and which are coincidence.

Fix: `docs/DESIGN.md` with the tokens, the 3 dials, the two sheet widths, the table-fold contract and the provider-hue rule.

### M2. Built-in providers show a bare dash where the URL goes (C-1)

In the Providers registry, Gemini and ElevenLabs render `-` in "Base URL", followed by a `builtin` word and a wire tag (`gemini`). Three marks for one fact, and the dash reads as missing data rather than "resolved at runtime".

Fix: replace the dash with `resolved at runtime` (or drop the separate wire tag when it equals the id).

---

## LOW: Quality Locks

### L1. Direct Vercel clone (R-30, R-20)

The stylesheet names its source: "Vercel style" (`ui.ts:2`), "Vercel dashboard restyle" (`ui.ts:1892`), "the Vercel dashboard vocabulary". Swap the logo and the console is a Vercel dashboard: same canvas, same 1px cards, same pill tags, same black primary button.

The user never asked for Vercel. Keep the monochrome discipline (it works for an operator tool), but give the console one signature of its own. The provider split bar is the obvious candidate: make it the identity element rather than a row inside a card.

## Resolution (2026-10-26, same day)

All HIGH and MEDIUM findings fixed in one change set.

| Finding | Change |
|---|---|
| H1 | `.grid-2:has(.table)` re-folded at 720; heatmap `<table>` wrapped in `.sr-only` div. Stats and Logs scrollWidth now 390 at a 390 viewport. |
| H2 | Providers header moved into `<thead>`; column widths retuned to sum exactly 1150px; URL is the only ellipsized cell; action column sticky right from 720 to 1400. |
| H3 | `--text-3` `#6b6b6b` light / `#8a8a8a` dark. |
| H4 | `--prov-gemini` `#0057c2` light. |
| H5 | `--tap-sm` 44px on coarse pointers. |
| H6 | Both strings rewritten without the dash. |
| M1 | `docs/DESIGN.md` added. |
| M2 | Built-ins read `runtime-resolved` with an explanatory title; the redundant wire tag was removed from the cell. |

Re-verified with the same harness: 8 pages, 2 themes, 390 and 1440. Zero document
overflow, zero console errors, zero AA contrast failures in rendered text. The
only remaining `contrast` hits are transparent 0px measurement spans, not copy.
L1 (borrowed Vercel identity) is intentionally left open: it is a direction
decision, not a defect, and needs the operator's call.
